# Contributing


Thanks for your interest in improving this project.


## What forms of contribution are most welcome?

- I am most interested in real world usage feedback through [issues](https://github.com/html-to-text/node-html-to-text/issues) and [discussions](https://github.com/html-to-text/node-html-to-text/discussions).
  - Besides addressing direct bug reports and feature requests, any feedback helps me to grow the understanding of how the library is used in practice and to prioritize directions for future development.
  - This is often more helpful than a PR, because "Why?" is more important than "How?" for me to shape the project.
- If there are open issues with label "help wanted" or "request for comments", these should contain a description of the problem and what kind of help is needed.


## If you still want to help with the code

For any non-trivial change, please make sure to discuss it first.

- If there is an open issue for the feature, comment there and ask to contribute.
- If there is no issue, open one first and describe the problem and your proposed solution.
- If there is a related issue but it is closed, open a new issue and link-mention the closed one for context.

Doing work without prior discussion may lead to misaligned efforts and discarded PRs.

Refer to [pull request template](.github/pull_request_template.md) to see all expectations for PRs ahead of time.


## Need help?

In case of any questions about contributing, feel free to ask through issues or discussions.
